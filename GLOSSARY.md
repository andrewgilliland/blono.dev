# blono.dev

The community site for Bloomington-Normal developers: where people find out about local meetups and learn from free workshop material.

## Events

**Event**:
A scheduled in-person gathering of the Bloomington-Normal developer community, held at a named venue with a start and end time.
_Avoid_: Meetup, happy hour (a happy hour is one kind of Event, not a synonym)

**Upcoming Event**:
An Event that has not yet ended at the moment someone is looking at it, including one that is in progress.
_Avoid_: Future event, scheduled event

**Past Event**:
An Event that has ended.
_Avoid_: Previous event, archived event

**Next Event**:
The Upcoming Event with the earliest start time.

**Event Time**:
Every Event date and time is stated in Central Time (America/Chicago), regardless of where the viewer is.

## Learning

**Workshop**:
A themed, ordered course of learning material, such as React Fundamentals.
_Avoid_: Course, class, tutorial

**Lesson**:
A single numbered unit within a Workshop.
_Avoid_: Post, article, chapter
